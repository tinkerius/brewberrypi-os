Networks

        
The Pi joins the first of these it can reach. Without one for 90 s it opens its own
          hotspot ; join it and this page opens (or go to http://10.42.0.1:8081/).
          While the hotspot is up, the Pi looks for these networks every 3 minutes when no device is connected to it.

        

      

      

        
Add a network

        

        

        

        

          
          
          
          
          

        

        
If you reached this page through the hotspot, the hotspot closes a few seconds after saving while the Pi joins the network:
          connect this device to the same network and open . If the Pi can't join it,
          the hotspot comes back within a minute, and this page says why.

      

      

        
Wi-Fi country

        
Which channels the Pi may use. Without it, a network on 5 GHz or on channels 12 and 13 may not be found.

        

          
          
        

      

      

        
Hotspot password

        
An open hotspot lets anyone nearby join it, so the app (port 8080) is blocked on it: only setup works there.
          With a password (8 to 63 characters) the app can be used over the hotspot too, for brewing without a home network.
          Leave the field empty to make the hotspot open again.

        

          
          

        

      

    


    

      

        

        

        

          
          
        

      

      

        
Installed

        

        

          
          
          
          
        

        
Installing, rolling back, restarting and demo mode restart the app, which ends a running brew.
          An install is watched for 60 s and rolled back automatically if the new version fails.

      

      

        
Available versions

        
Download a version onto the Pi first, then install it. Downloads stay on the Pi until you remove them,
          so switching between them needs no internet. The active and the previous version are always kept. 

        
The Pi checks the registry for a newer version every 6 hours and shows it at the top of every page; it never installs
          one by itself while an app is installed. Until the first app version is installed, it installs the newest one by itself.

        

        

        

      

    


    

      

        
Current configuration

        

        

        

          
          
        

      

      

        
Import

        
Upload config.json (or other .json files), recipe files, or a .tar.gz downloaded above.
          Every file is checked first; nothing changes if one is invalid. Replaced files are backed up on the Pi (os/backup).
          New recipes show up in the app within a few seconds; config.json it reads at start: restart it afterwards.

        
        
        

          
          
        

      

      

        
File share

        
The configuration is shared on the network: open  in Windows Explorer, or 
          in macOS Finder (Go, Connect to Server) or a Linux file manager, and log in as brewberry with the password of this page.
          It has two folders: app (the app's config.json and recipes/) and os (Wi-Fi settings and backups).
          Nothing checks a file saved there. A recipe file saved in app/recipes shows up in the app within a few seconds;
          config.json the app reads at start, so restart it after changing it, and look at Current configuration if it doesn't start.

      

    


    

      

        
Operating system update

        

        
Keep the power connected from Maintenance mode on until
          Maintenance mode off has rebooted: in between the system is writable, and pulling the plug can damage it.
